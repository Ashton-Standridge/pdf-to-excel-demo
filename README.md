> **Sample / demo project.** Not client work. The contract PDF is fake and generated by `make_sample.py`; no real people or properties are involved.

Reads a real-estate purchase agreement PDF, pulls out 15 key fields, writes them to an Excel workbook, and builds a deadline timeline from the accepted (binding agreement) date using live Excel formulas.

![Sample output: Fields and Timeline sheets](screenshot.svg)

## The problem
Agents and transaction coordinators retype the same numbers from every contract (buyer, seller, price, earnest money, contingency periods) and then count days on a calendar to find each deadline. It's slow, and a deadline that lands on a weekend is easy to get wrong.

## Features
- Extracts 15 fields: parties, address, parcel ID, price, earnest money and holder, seller contribution, financing, contingency periods, closing.
- Opens password-protected PDFs with `--password`, with a clear error when the password is missing or wrong.
- Two-sheet workbook: **Fields** (money stored as real numbers) and **Timeline**.
- Timeline uses live Excel formulas: change the yellow accepted-date cell and every deadline recalculates.
- Saturday/Sunday deadlines roll to Monday and are flagged in a Note column.
- Lists any field it could not find, so nothing goes missing silently.

## Quickstart
```bash
git clone https://github.com/Ashton-Standridge/pdf-to-excel-demo.git
cd pdf-to-excel-demo
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python make_sample.py      # creates samples/ (plain + protected copy, password demo1234)
python extract.py samples/purchase_agreement_sample.pdf --accepted 2026-10-22 -o output/purchase_agreement.xlsx
python extract.py samples/purchase_agreement_protected.pdf --password demo1234 --accepted 2026-10-22
```

## How this maps to client work
| If you need… | This demo shows… |
|---|---|
| Data pulled from invoices, contracts, statements or reports | Label-based field extraction that is easy to retarget (`LABELS` in `extract.py`) |
| A spreadsheet your team can keep using | Real numbers and live formulas, not pasted values |
| Confidence nothing was missed | A report of every field that wasn't found |
| Locked files | Password-protected PDF support |

**Limits:** real contracts vary by state and form, so a new form usually means adjusting the label list and patterns. Holidays aren't handled in this demo; they'd be a small addition.
